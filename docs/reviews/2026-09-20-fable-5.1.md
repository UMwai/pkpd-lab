## UI changes following user feedback

The workbench now uses a compact light layout with grouped parameter controls,
an accessible PK topology diagram, readable exposure metrics, a full-width
concentration chart, and separate response and dose-schedule panels. Import mode
hides unrelated builder controls. PD controls show only the parameters relevant
to the selected response. Population results use a shaded percentile band.

Concentration traces have gaps at bolus boundaries to avoid suggesting an infusion
ramp. Direct plasma-driven PD uses the same discontinuity convention; continuous
effect-site and turnover responses remain continuous. The plotted concentrations,
metrics, and exported engine output are unchanged. Presentation tests check that
plotting does not mutate the source data or invent concentrations for log axes.
